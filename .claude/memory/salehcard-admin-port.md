`/admin` is a **separate** Vite + React + TS app (port 5174) ported from the Claude Design admin prototype (bundle fetched from an api.anthropic.com/v1/design share link — links expire, ask for a fresh one). It sits alongside `/web`; do not modify `/web` when changing `/admin`. See [[salehcard-dev-env]] to run it and [[salehcard-design-port]] for the storefront's matching approach.

Key decisions (user's prompt left several as "my call"):
- **Design tokens duplicated, not a shared package** (pragmatic). `admin/src/styles/{base,admin}.css` are the prototype's CSS ported verbatim (base = brand tokens + primitives, admin = dense chrome: sidebar/topbar/tables/KPIs). Tailwind maps the same CSS vars. Design system is CSS classes (`.abtn .acard .tbl .bdg .st-* .ff-* .kpi .sidebar`), NOT Tailwind `dark:` — same as `/web`.
- **Routing** uses react-router-dom (not the prototype's localStorage view-state). `RequireAdmin` guard → `/login`. Theme persists; locale forced English on load (handoff rule). Sidebar collapse persisted in a `ui` zustand store.
- **Fulfillment color-coding** consistent via `<FfBadge>`: blue=code, green=account_credit(credit), orange=transfer.

**Wired to the Go API:** `products` (list/create/edit/delete/bulk), `inventory` (code stock, bulk upload w/ dedup, threshold config, code audit), dashboard KPIs + low-stock, (shipped 2026-06-27, PR #8) **`orders`** (list w/ server filters+search+pagination, detail) + **`dashboard`** revenue/orders/deltas, pending-transfers, revenue chart, fulfillment donut, recent orders, and (2026-06-27, full-stack) **`users`** — list (role/status/`q` filters + pagination + per-page order-count/spent aggregation), detail (overview/orders/wallet/IDs/role tabs), role change, suspend/reactivate, and manual wallet credit/debit (atomic + `wallet_transactions` ledger). Backend: implemented `user/admin.go` 5 routes, added `User.Status` (active/suspended; empty=active for legacy), `UserFilter`/`ListAll`/`UpdateRole`/`UpdateStatus`, and **suspension is enforced at login** (Login/LoginByPhone/VerifyOTP/Refresh → 403 `ACCOUNT_SUSPENDED`). Cross-module: `user/admin.go` reaches the orders collection raw (no `order` import) since `order` imports `user`; uses `wallet.Repository` directly. Orders tab reuses the wired orders endpoint via `useOrders({q: email})`. Seed adds ~6 demo users. And (2026-06-27, full-stack, **merged PR #10, live in prod**) **`resellers`** — a reseller is a `user.User` with `role=reseller`; the `reseller` module's `ResellerTier` was **repurposed** as a shared tier definition (`name`/`marginPercent`/`balanceLimit`, collection `reseller_tiers`) and the per-reseller tier is a new `user.User.resellerTier` (tier name) field. Admin: implemented `reseller/admin.go` 8 routes — reseller list (tier/status/`q` filters + pagination + per-page order-count/volume aggregation + tier-margin enrichment), detail (overview/sub-balance/order-history + ComingSoon pricing tab), **tier assignment** (validates tier exists), **sub-balance adjust** (reuses the user **wallet** Credit/Debit + `wallet_transactions` — sub-balance IS the wallet, no separate ledger), and **tier-definition CRUD** (dup name→409, bad margin→400). Cross-module: `reseller` imports `user`+`wallet` and reads the `orders` collection raw (order imports user → keep acyclic). **Tier margin is config/display-only this pass** — order pricing still uses the per-variant `product.Variant.ResellerPrice`; wiring margin into checkout is a deliberate deferred follow-up (PO call). Deleted dead `reseller/{service,handler}.go` stubs. Seed (`reseller/seed`) upserts Bronze5%/Silver8%/Gold12% + assigns the 3 seeded resellers; runs after user seed in `cmd/seed`. And (2026-06-27, full-stack, **merged PR #11, live in prod**) **`finance`** — the admin finance page (`features/finance`, route `/finance`).
