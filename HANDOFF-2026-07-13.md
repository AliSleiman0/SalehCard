## Gotchas on this machine
- **pnpm:** repo/CI use **pnpm 9**; this box has **pnpm 11**, so `pnpm test` exits 1
  (`ERR_PNPM_IGNORED_BUILDS` on esbuild/core-js). Tests are fine — run `node_modules/.bin/vitest run`
  directly, or pin pnpm 9. CI (pnpm 9) is unaffected.
- **Windows downloads:** use `curl.exe`, not `Invoke-WebRequest` (its progress bar throttles PS 5.1).
- **Elevation:** winget installers launched detached can't show their UAC prompt — run elevation in the
  foreground (`Start-Process -Verb RunAs`).
- **Release builds** need an HTTPS `API_BASE_URL` dart-define (cleartext is debug-only).
- **`/bridge` app must never go to Play** (AccessibilityService USSD automation → policy violation).

## Moving to another machine
Repo + `salehcard-migration-secrets.zip` + this doc = everything essential. To skip the slow
re-download, copy `%LOCALAPPDATA%\Android\Sdk` (SDK + NDK, ~2 GB) and `%USERPROFILE%\.gradle`
(Gradle cache). Then re-auth gh / gcloud / firebase / az and re-set the repo-local git identity.
